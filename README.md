# BuiltPulse Web

Next.js 15 + Tailwind implementation of the BuiltPulse (business setup / PRO / compliance, Dubai UAE) Figma landing page.

## Stack
- Next.js 15 (App Router)
- React 19
- Tailwind CSS 3.4
- TypeScript 5

## Run
```bash
npm install
npm run dev
```
Open http://localhost:3000.

## Design source
Figma: Builtpulse — Landing Page. Tokens, components and sections mirror the file's design-system page (`02 · Design System`). Hero image lives at `public/images/hero-dubai.png`.

## Sections
1. Hero + floating nav + live Assessment form (step 1)
2. Trust metrics (overlapping stat cards)
3. Business lifecycle explorer (interactive tabs)
4. Client logo strip (marquee)
5. Services (4 featured + 8 secondary of 12)
6. Achievements & milestones
7. Client testimonials carousel
8. Senior consultant CTA
9. FAQ + Business audit form
10. Insights / blog
11. Footer CTA band + columns

## Placeholders
Several sections ship with placeholder copy (badge names, metrics, achievements, testimonials, FAQ answers, email, blog images) that match the Figma file's own placeholder convention. Replace before launch.
